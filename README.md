# UnSpot — промежуточная версия

Выбор тестовой компании по поддомену `uit-dev-products`, ru/en. Проверка компании обращается к существующему API. Экран входа пока является заглушкой.

В корне только production-сборка клиента и публичная конфигурация. Предыдущая диагностика связи сохранена в `diagnostics/`.

`404.html` запускает Angular для прямых маршрутов GitHub Pages; HTTP-ответ на такой маршрут остаётся 404. Это ограничение тестового статического хостинга, а не production rewrite.
