# Проверка подключения UnSpot

Временная статическая страница для проверки связи с тестового хостинга: определение компании, вход, текущий пользователь и обновления Mercure. Это не поставка нового клиента.

Запуск локально: `python3 -m http.server 8080`, затем открыть `http://localhost:8080/`. Внешние зависимости не нужны. Для проверки требуются собственные разрешённые данные входа, вводимые в форму; в файлах их нет.

Адреса API и тенант задаются в `config.json`. Страница намеренно разрешает авторизацию только на известных тестовых API/auth origins из `probe.js`. Изменение окружения требует синхронного обновления allowlist и CSP `connect-src` в `index.html`.

`privateMercureUrl` получен из конфигурации действующего тестового клиента; origin указан в `allowedMercureOrigins` и CSP `connect-src`. При смене хаба нужно обновить оба ограничения. Само наличие конфигурации не доказывает успешное подключение. Topic строится из настроенного тенанта. Токен подписки передаётся в query так, как требует действующий API; адрес соединения, токены и содержимое событий страница не печатает и не сохраняет.

Открытое соединение и полученное событие показаны отдельно. Страница ничего не публикует: безопасное событие должен вызвать отдельный разрешённый тестовый сценарий. После первого события, ошибки, таймаута, очистки или ухода со страницы соединение закрывается. Отсутствие события не считается успехом.

Пароль очищается из поля сразу после отправки формы. Данные авторизации используются только в памяти вкладки; постоянное хранилище, cookies, аналитика и сторонние скрипты не используются. Ответы API и персональные данные в результатах не отображаются.

Meta CSP ограничивает загрузку ресурсов. Защита от встраивания требует HTTP-заголовка `Content-Security-Policy: frame-ancestors ...` на хостинге: meta-тег не может установить эту директиву. Настройка заголовков проверяется отдельно от этой страницы.
