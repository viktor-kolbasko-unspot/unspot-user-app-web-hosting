# UnSpot — промежуточная версия

Тестовая компания: `uit-dev-products`. Доступны выбор по поддомену, парольный вход с реальным API и просмотр профиля, ru/en. Профиль пока без сохранения изменений.

Добавлены экраны нового пароля по ссылке, заявки на доступ и подтверждения отправки заявки. Прямой вход на экран подтверждения сам по себе не означает отправку заявки. Доставку писем и действие по настоящей ссылке проверяет заказчик.

В корне только production-сборка клиента и публичная конфигурация. Предыдущая диагностика связи сохранена в `diagnostics/`.

`404.html` запускает Angular для прямых маршрутов GitHub Pages; HTTP-ответ на такой маршрут остаётся 404. Это ограничение тестового статического хостинга.
